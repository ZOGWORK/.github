# ZOGWORK

FTC robotics software — scouting, predictions, team management, and robot code.
Named after Zog, the golden retriever.

## The Control family

| Project | What it is |
|---|---|
| [Control Scout](https://controlscout.org) | Free FTC scouting + match predictions for every team. Publishes its prediction accuracy openly. |
| [Control Point](https://tryctrlpoint.org) | Team management for robotics teams, with built-in AI. |
| Control Kit | Onshape assembly BOM and purchasing tool for FTC teams. |
| Control Vision | Local-first FTC match video analyzer — track robots, count cycles, clip highlights, score matches from video. |

## Robot code

- [BioHORS](https://github.com/ZOGWORK/BioHORS) — FTC BIOBUZZ 2026-27 robot code: teleop + auto for team 33950, First Street Kids Robotics.

## Other tools

- [Wyze Print Monitor](https://github.com/ZOGWORK/wyze-print-monitor) — watch and control a Wyze Cam on your 3D printer, with local AI print-failure detection.
- [CleanYourTV-WebOS](https://github.com/ZOGWORK/cleanyourtv-WebOS) — a clean home screen for rooted LG webOS TVs.
